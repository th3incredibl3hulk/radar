## Future Maintenance

### Bi-Weekly Cadence

Research-pulse runs on **even ISO week numbers** (34, 36, 38, ...). Odd weeks skip it. This reduces noise since research papers don't ship on a weekly cadence like product releases.

### Adding More Researchers

To add more researchers to research-pulse or agentic-coding:
1. Edit the agent file (`agents/research-pulse-reporter.md` or `agents/agentic-coding-reporter.md`)
2. Add to the appropriate tier with their blog URL + X/Twitter handle
3. The next run will automatically start tracking them

### Skeptic Audits

Run the skeptic agent periodically to audit whether the new researcher/developer tiers are pulling weight:

```bash
claude --agent skeptic -p "Audit my sources. Today is 2026-08-17."
```

The skeptic will check if the new sources are surfacing unique signal or just duplicating what newsletters already cover.
