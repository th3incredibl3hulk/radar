## Stories filed as of 2026-07-13 (do not re-report unless there's a material update)
- China's MIIT issued a formal "backdoor" warning on Claude Code (flagged versions 2.1.91-2.1.196), citing the same tracking-marker code covered last cycle. Alibaba banned employee use of all Anthropic tools as of 2026-07-10, redirected staff to its own "Qoder" assistant. Anthropic's response: flagged China-based users weren't supposed to be running Claude Code per ToS (bars majority China-owned entities). By 2026-07-13, Bloomberg reported this had escalated into a broader DC policy debate about distillation/model-extraction rules. Underlying dispute traces to Anthropic's June Senate letter accusing Alibaba-affiliated entities of ~28.8M fraudulent queries over 6 weeks to distill Claude. **Live/developing — check next cycle for regulatory action or further corporate bans.**
- "Friendly Fire" (AI Now Institute, disclosed 2026-07-08): prompt injection via ordinary repo files (e.g. README recommending "run security.sh") achieves RCE against Claude Code (Sonnet 4.6/5, Opus 4.8) and Codex CLI (GPT-5.5) when in default auto-mode/auto-review — i.e. while the agent is doing an automated security review. No hooks/skills/plugins/MCP/config needed. Design-level flaw (agents can't separate task instructions from hostile content encountered while doing the task). More severe than GuardFall (filter bypass) or GitLost (data leak) — this is code execution. (Was flagged "not deep-dived, revisit" in the prior memory — now covered.)
- Sophos research (published 2026-07-08): AI coding agents (Claude Code w/ `--dangerously-skip-permissions`, Cursor, OpenAI Codex) trigger EDR/endpoint-detection rules built for human attackers. 56.2% of flagged activity was credential access (DPAPI browser-credential decryption = 42.6% of that), 28.8% was execution behavior (certutil/bitsadmin downloads, PowerShell, startup-folder writes). Non-adversarial — a detection-signal-quality problem that scales with agent adoption.
- Claude Fable 5 free-access window extended a SECOND time: July 7→12 (first extension, already known), then July 12→19 (second extension, announced hours before the prior deadline). Both kept the 50% Claude Code weekly rate-limit boost. July 20 target for credit-based billing ($10/$50 per M tokens) unchanged but now delayed twice; Anthropic says it wants to restore subscription access "once capacity allows." **Check next cycle for a third extension or the actual cutover.**
- SWE-bench Pro leaderboard (as of 2026-07-13, per llm-stats.com and benchlm.ai, cross-checked): Claude Fable 5 leads at 80.0%, unannounced "Claude Mythos Preview" second at 77.8%, Claude Opus 4.8 third at 69.2% (matches last cycle's single-source figure, now corroborated), Grok 4.5 (64.7%), GPT-5.6 Sol (64.6%). "Mythos" not yet an announced/confirmed Anthropic product name — watch for an official announcement.
- GitHub CodeQL 2.26.0 (2026-07-10): added JS/TS query for AI prompt-injection detection (untrusted values flowing into AI system prompts) plus new sinks for OpenAI/Anthropic/Google GenAI SDKs — also Kotlin 2.4.0 support, C# Razor Page remote-flow-source improvements.
- GitHub Copilot CLI v1.0.70 (2026-07-09): `--sandbox`/`--no-sandbox` session flags, repo-level policy pinning (model/effort/context-tier, deny-list extension) via `.github/copilot/settings.json`, SDK APIs to manage live MCP servers mid-session, `/refine` command.
- Simon Willison, "Directly Responsible Individuals (DRI)" (2026-07-12): agents should never be the DRI for a task/project — accountability must stay human even as delegation to agents becomes routine.
